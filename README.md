## `$ ls ~/projects`

### ReVolt — Battery Lifecycle & Recycling Platform

A platform prototype for battery registration, explainable safety assessment, recommended end-of-life pathways, and collection logistics.

- Backend: FastAPI and Pydantic
- Assessment engine: deterministic, explainable rules
- API capabilities: battery records, assessments, logistics, and OCR parsing
- Goal: improve battery traceability and responsible recycling decisions

### Archon Infra — Cloud Infrastructure

A static website deployment architecture using AWS storage and content delivery services.

- Private S3 bucket
- CloudFront with Origin Access Control (OAC)
- Versioning and lifecycle configuration

### Smart Lab Monitoring System

An IoT-oriented lab monitoring project using an ESP32 and sensors.

- ESP32
- DHT11 temperature and humidity sensor
- MQ-2 gas sensor
- PIR motion sensor
- OLED/LCD display
